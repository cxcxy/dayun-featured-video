# 大昀精选视频验收表

“精选风格”不能只靠主观感觉。先通过硬性检查，再做正常速度观看。

验收范围：新制作或全局改动覆盖整片；局部修改覆盖受影响段及前后相邻边界；精确截断重点覆盖末句、片尾和截止点。全局字幕、声音、共享布局、时间映射、帧率或渲染设置改动须升级为整片。记录实际时间范围，检查中发现范围外问题时扩大范围。

## 一、硬性失败项

在本轮验收范围内，以下任一项存在时，不得标记为完成；已知的范围外问题也要披露，不能借范围声明掩盖：

- 用户没有明确要求省略或替换时，开头缺少片头转场，或只做标题淡入、直接硬切正文（新制作或片头改动时检查）。
- 正文镜头之间缺少可见连续转场，仅以硬切或换背景代替交接。
- 流程介绍主要靠几组卡片轮播，能用具体插画解释的对象、动作和结果没有视觉演示。
- 同一插画在不同讲解段落重复出现，包括裁切、镜像、换色或换标签后的复用。
- 目标截止时间之后仍有画面、字幕或声音。
- 任一镜头边界出现意外空白、黑帧或闪帧；设计中的重叠交接允许旧画面短暂可见，但转场完成后不得意外残留。
- 转场用纯色全屏遮罩造成可感知停顿。
- 字幕被裁切、遮挡、一次堆满或与当前语义错位。
- 重点词缺少图中对应位置的中文标注，标注指向不明，或画面、动作、标注与实际发音和字幕抢跑/滞后。
- 明暗切换只改变底色，既没有新的语义任务，也没有内容或关系的可辨变化。连续录屏和逐步操作可保留原构图。
- 手绘图需要解释才能看懂，或在一张图里塞入多个关系。
- 插画或中文文字模糊、过小、出现太短，或看不出操作主体、对象、关系及结果。
- 官网截图小到无法辨认，且没有中文结论承担信息。
- 音频在句中硬切、爆音、削波或被背景音乐盖住。
- 用户未要求无音效时，适合的转场、操作和状态落点没有音效，或音效与事件错位、被混音淹没、遮住关键词。
- 产品能力、价格、速度和限制没有来源或边界说明。

## 二、渲染前检查

### 内容

- 核验脚本、字幕和画面文字中的中文、数字、产品名和时间点。
- 确认字幕数量、顺序和文字与核验稿一致。
- 截断版过滤 start 大于等于截止点的字幕，并把最后一条 end 限制到截止点。
- 每个语义单元只出现一次，没有遗漏或重复。
- 逐个核对关键词同步表的实际发音、字幕、插画对象、中文标注、动作和音效；句内关键词使用独立锚点。
- 插画使用表包含源文件与使用区间；检查全片缩略图，确认无跨段复用或改形复用。

### 构图

- 测量每条字幕和每个渐进节点是否超出容器。
- 检查标题、截图、角色和字幕安全区。
- 连线终点落在实际节点附近。
- 检查相邻场景是否有明确的新语义任务；默认参考蓝图改变内容维度，连续演示可保留构图。
- 中文标注靠近对应对象，指向明确、可编辑且无错字；按最终显示尺寸检查插画清晰度与手机可读性。
- 每幅解释图能直接说清当前对象、动作、关系和结果；看不懂的图必须重做。

### 手绘插画与辅助文字

在本轮验收范围包含手绘设计或辅助文字改动时，对照 [文字预留与口播联动规范](illustration-text-sync.md) 检查：

- 无文字底图、独立文字层、布局说明及文字联动表齐全；底图留出 2–3 个干净区域，不含占位字、乱码或内部编号。
- 每个文字区关联明确的口播原句和画面对象；实际文字试排后无溢出、重叠、遮挡或小字，运动路径不侵占文字区。
- 出现、完整可读和结束时间使用关键词同步表的真实音频基准，逐项出现且当前重点明确。
- 往返 seek 检查无文字、单项出现、多项保留和退场状态；从最终 MP4 抽查对应状态及正常速度口播同步。局部验收范围与整片升级条件沿用本表。

### 时间线

- 片头包含主题建立、双页展开和正文落点；首个正文从 0 秒起已挂载，正文入场与展开交叠，默认约 1 秒接稳，不推迟第一句口播。
- 场景无间隙；普通边界包含约 0.1 秒预加载和约 0.42 秒重叠交接。
- 章节边界包含约 0.52 秒交接；完整不透明的底层保留到新场景覆盖完成，移动和缩放限于内层，四边及中间帧不能透出无信息底色。
- 每个场景的选择器限定到自身 sceneRoot；在同一 DOM 同时放两个带同名 class 的场景，seek 任一子时间线不得改变另一场景。
- 所有 Timeline 可从任意时间 seek 并恢复正确状态；前进、后退和随机顺序到同一时间点结果一致，包括预加载时间被 0 截断的首场景。
- 字幕使用真实口播的独立时间线；专测转场中换句，不被推迟、不重置且始终置顶。
- 没有 CSS 动画、真实时钟、定时器或无种子随机运动。
- 视觉事件按实际输出帧率映射到关键词锚点，误差不超过一帧；音效入点或重音与视觉事件对齐，转场不延误重点的可读时刻。

## 三、编码后技术检查

- 用 ffprobe 核对分辨率、恒定帧率、帧数、时长、视频编码、像素格式、音频采样率和声道。
- 完整解码最终 MP4，记录解码错误。
- 扫描黑帧、异常静音、响度、True Peak 和最后有效发音。
- 导出全部帧时间戳；预期 30fps 时，相邻差值应约为 0.033333 秒。
- 存在桌面副本或上传文件且未被平台转码时，核对它们与源导出的 SHA-256；平台转码后改核对媒体规格与关键画面。

## 四、逐转场抽帧

新制作、全局改动或片头受影响时：片头单独检查最终 MP4 的首帧及约 0.15、0.30、0.50、0.75、1.00、1.20 秒画面；若调整过时长，按实际展开起点、中点、终点及终点后一帧补查。确认首帧有主题信息、左右页同步展开、正文连续显露、字幕未被遮挡，且片头退出后没有残留。编辑器内另做从正文回 seek 到片头、再跳到正文的检查，确认状态一致。

新制作或全局改动的每个转场至少检查以下 6 个实际编码帧；局部修改检查受影响转场及相邻边界，精确截断重点检查截止点前后和片尾。时间点以实际编码帧中最近的帧为准：

1. 切点前约 0.10 秒。
2. 切点前约 0.03 秒。
3. 切点。
4. 切点后约 0.10 秒。
5. 切点后约 0.22 秒。
6. 切点后约 0.42–0.55 秒。

检查：

- 新画面已存在，没有空白。
- 前后画面在中间帧同时交接，普通和章节转场的四角、四边都无透底；转场结束后无旧画面残留。
- 运动方向一致且没有突然反向。
- 字幕保持最高层。
- 需要切换明暗主题或内容组件时，在同一连续动作中完成；连续录屏和逐步操作可保留构图。
- 章节角标没有遮住标题、来源或字幕。

新制作或全局改动把全部转场排成接触表，并生成覆盖所有场景的主接触表；局部修改只需覆盖受影响场景及相邻边界。抽帧检查必须来自最终 MP4。

另按关键词同步表逐点抽查最终 MP4：发音前一帧、锚点帧、动作落点和退出前帧，核对对应字幕、插画、中文标注及结果揭示。逐点试听音效与口播，抽帧不能代替听觉同步检查。

## 五、正常速度观看

自动检查通过后，新制作或全局改动必须整片正常速度观看和试听一遍；局部修改观看和试听受影响段及前后相邻边界，精确截断观看和试听完整末句到片尾。按实际范围检查：

- 开头 3 秒是否马上给出收益或冲突。
- 切镜是否贴着语义结束，而不是抢话或拖延。
- 转场是否被注意到但不打断理解。
- 重要截图是否有足够阅读时间。
- 静止画面是否在承载阅读，而非节奏停滞。
- 字幕是否跟得上口播且没有频繁闪烁。
- 读到重点词时，目光能否立即找到图中中文标注与对应对象，动作是否正好解释当前字幕。
- 不回放、不暂停时，是否能说清每一步的输入、操作与结果；任何模糊或需要猜测的段落退回重做。
- 插画是否丰富且每幅只用于一个连续段落，流程是否仍有大段卡片轮播。
- 音效是否在合适事件处清楚可辨、对齐动作且没有遮住重点词，转场是否连贯并保留阅读时间。
- 最后一句是否完整，淡出是否自然。

记录实际正常速度观看和试听的时间范围。局部验收写明“受影响段及相邻边界已检查，未做整片正常速度观看和试听”，不能写成整片已经完全验收。新制作或全局改动未完成整片观看时，写明“整片连续人工审片未完成”；只有确实完成对应技术检查和编码抽帧后，才能说这些项目通过。

## 六、精选自查评分

评分只用于内部复核，不保证平台精选结果。任何硬性失败项都优先于总分。

| 项目 | 分值 | 满分标准 |
| --- | ---: | --- |
| 开头钩子 | 15 | 3 秒内说清收益或冲突，标题层级清晰 |
| 语义剪辑 | 20 | 每次切镜都有内容理由，阅读时间充足 |
| 转场连续性 | 20 | 前后画面重叠交接，无空白和幕布停顿 |
| 视觉解释 | 15 | 独立插画丰富且不跨段复用，中文标注明确，操作与因果一眼可懂 |
| 字幕与节奏 | 10 | 关键词、标注、动作严格同步，短句完整置顶，语义音效对齐且不遮旁白 |
| 可信度 | 10 | 来源、假设、实测和限制边界清楚 |
| 技术质量 | 10 | 高清、恒定帧率、无解码和音频问题 |

90 分以上且没有硬性失败项，可作为“精选候选版”进入最终人工审片。

## 七、交付包

至少包含：

- 逐字稿。
- 最终高清 MP4。
- AI 制作记录。
- SRT 字幕。
- 素材来源与授权说明。
- 关键词同步表、插画唯一使用表与音效编排/混音检查记录。
- 开头静帧和短预览（新制作或开头修改时）。
- 章节索引（有章节时）。
- 质检说明，列明未执行的检查。
- 代表性转场预览（存在转场或转场修改时）。

保留可复现源工程和旧版，不覆盖唯一素材。

使用手绘插画时，源工程另保留无文字底图、独立辅助文字层、文字区布局说明和已校准的文字联动表。
