# 大昀精选视频制作蓝图

这份蓝图来自一支通过精选的 JEV 信息讲解视频。参数是经过实际成片验证的起点，可以随主题、语速和画幅调整；核心关系不能丢失。

## 1. 先搭叙事骨架

按以下顺序组织信息，缺少某一环时再按内容裁剪：

1. 收益或冲突：用户为什么现在要听。
2. 一句话定义：产品或方法到底是什么。
3. 真实证据：官网、GitHub、数据、录屏或明确标注的案例。
4. 机制解释：具体对象的动作演示、因果插画、流程图或对比；短卡片只作辅助。
5. 接入方法：用户下一步怎么做。
6. 成本、速度和适用边界：同时说清限制。
7. 决策建议：哪些交给代码、轻模型、大模型或人工。

不要连续堆观点。结论之后尽快给证据；证据之后再用图形解释，避免把解释图冒充真实产品界面。

## 2. 片头的三层结构

开头必须有一次内容可见、连续交接的转场，默认采用 [GSAP 动效配方](gsap-recipes.md) 的“双页打开”，不能以单独的标题入场代替。用户另有明确要求时优先遵循。

片头转场默认安排：

- 0 秒：首帧已有可识别的主题词或主题图形；首个正文场景预先挂载在片头下方，素材和字体准备完成。
- 约 0–0.30 秒：主题词、强调线与短句建立，口播正常开始。
- 约 0.30–0.98 秒：左右页面同时向两侧打开，正文标题或主素材随展开过程出现；不能等片头完全退场后才启动正文。
- 约 1 秒：首个正文镜头接稳。主题插画或证据按语义继续展开，字幕始终位于片头层上方。

上述时间是默认节奏，可按真实口播微调；不得为片头添加无信息等待、延后第一句或改动已确认音频。双页是承载主题的片头内容，不能退化成没有信息的纯色幕布。

以 1920×1080 横版为基准：

- 第一层：0–1 秒短引入。品牌词或主题词快速建立，随即打开正文，不让用户等待。
- 第二层：顶部收益句，直接回答“能帮你做什么”。约 42–52px 粗体，保持一行或两行内。
- 第三层：居中主标题，约 120–154px 真粗体，从上方落入；标题只保留一个冲突。
- 主标题旁或下方用主题插画演示冲突或收益；信息适合并列时可辅以短卡片，每张只写一个短句，不固定套用三卡布局。

进入顺序应在一秒左右建立：主题词和线条 → 收益句 → 主标题与主题视觉。细节继续跟随口播展开，字幕不与主标题争抢中心位置。

片头不加无关品牌角标。除非用户明确要求，画面只保留内容本身。

## 3. 语义切镜

每个镜头对应一个完整的语义任务。出现以下情况之一时切镜：

- 结论从“是什么”转为“怎么做”。
- 证据来源改变。
- 逻辑从事实转为机制、成本、速度或风险。
- 当前布局已经容纳 4–6 个渐进节点，继续添加会降低可读性。
- 口播出现明显的章节句或总结句。

典型镜头可保持 3–8 秒；复杂截图或流程可以更长，短强调镜头可以更短。时间不是硬指标，读完和看懂才是。

相邻镜头默认通过内容或构图变化建立新语义；可参考下列维度，通常改变两项即可。连续录屏、同一界面的逐步操作或刻意保持空间关系时，可以沿用构图，只要新镜头的语义任务清楚、可读且切镜有理由：

- 主内容组件。
- 构图方向或左右关系。
- 真实素材或图形类型。
- 信息密度。
- 明暗主题。
- 标题层级或流程方向。

## 4. 可轮换的内容组件

| 语义任务 | 推荐组件 | 画面重点 |
| --- | --- | --- |
| 定义产品 | 大标题 + 官网截图 | 截图保留真实来源，中文标题给结论 |
| 解释流程 | 输入对象 → 操作动作 → 输出结果的独立插画 | 读到对象或动作时，出现对应中文标注与动作 |
| 对比两个概念 | 左右双栏 | 每侧只放一个判断标准 |
| 多步骤方法 | 各步骤的具体操作插画 + 简短进度指示 | 每步画出当前操作和可见结果，避免只换卡片文字 |
| 选择或分类 | 选项 pills + 卡片 | 先出现选项，再落定结果 |
| 风险与兜底 | gate / 分岔图 | 清楚显示继续、复核、人工 |
| 成本 | 数字卡 + 比例条 | 数字注明是假设、官方或实测 |
| 速度 | 大数字 + 单位 + 测量边界 | 不把局部耗时写成端到端承诺 |
| 原始资料 | document / 网页截图 | 放大关键区域，不缩成看不清的整页 |
| 章节总结 | 四类分工或短清单 | 每项对应一个动作主体 |
| 收尾 | 大结论 + 行动建议 | 不引入新概念 |

同一组件连续使用超过两个镜头时，检查是否仍有新信息和足够的阅读时间；确有连续操作或对照关系时可保留。明暗切换应对应信息关系的变化，不强制为了换组件而打断演示。流程篇逐段检查插画机会：能通过对象、动作或因果关系讲清的内容，优先设计独立解释图；不设固定插画数量，不用增加无关装饰凑数，也不能因省事只留下卡片轮播。

## 5. 渐进字幕与流程节点

- 字幕按呼吸和语义切成短句，一个时段只显示当前短句。
- 当前字幕必须完整显示；过长时优先拆句，其次换行，最后才微调字号。
- 画面节点与字幕不是一回事。字幕负责“听懂”，节点负责“看懂”。
- 同一语义组的节点可以累计保留，让观众看到流程逐步完成。
- 当新语义组开始或页面容量已满，再切到新镜头。
- 箭头或连线跟随对应关系词的时间锚点绘制，不提前揭示未讲到的节点或结果。

### 关键词同步表

实际音频是时间基准，字幕必须先与发音核对；不能把整句字幕的起点当作句内所有关键词的起点。逐词对齐结果需人工复核中文、数字及专有名词。

每条重点事件至少记录：`字幕编号、关键词/短语、实际发音起止、场景编号、插画编号、解释对象、中文标注及位置、动作起点/落点、音效文件/入点/增益、转场起止`。字幕、视觉和音效共用该表的时间，不分别估算。

- 在关键词发音起点，使对应对象与中文标注可读，同时启动语义动作；先有对象，再让指向关系与动作说明操作，结果在口播读到结果时揭示。
- 插画框架可提前就位，重点标注和结果不可抢跑。标注放在被解释对象附近；有多个对象时，用明确指向线，不能让观众猜标签属于谁。
- 按输出帧率把视觉事件映射到最近编码帧，时间表与实现误差不超过一帧；这只证明实现对齐，还须正常速度听看确认发音锚点正确。
- 转场需要预留交接时间，使关键词发音时对应主体已清楚可见；必要时提前开始转场或简化动作，不为动画推迟字幕、改速音频或让重点藏在运动中。
- 标签保留足够阅读时间，语义完成后再退出；一屏只揭示当前讲解所需标签，不同时堆满所有术语。

1080p 横版参考：字幕 42–48px 粗体，左右安全边距约 140px，底部约 30–60px，最大宽度约 1640px。最终以投放平台安全区和实际字形测量为准。

## 6. 截图与证据

- 截图必须来自可追溯来源，保持原貌，只做裁切、放大、框选和轻微聚焦。
- 手机观看时看不清的英文截图不能独自承担信息；用中文结论解释其意义。
- 价格、速度、限制和产品能力要标注“官方说明、实测、案例或假设”。
- 录屏必须说明计时起点和终点，不能把“找到结果”说成“完成付款”。

## 7. 解释性插画与唯一使用

手绘用于抽象机制，不用于伪造产品界面。默认提示方向：

- quirky editorial sketch，白底，16:9。
- 粗细略有变化的黑色手绘线，轻微不规则。
- 一个画面只解释一个关系，主体占约 60–70%，留足空白。
- 最多两处柔和强调色，避免渐变、阴影、3D 和复杂纹理。
- 中文标签使用独立、可编辑的文字层，按关键词时间锚点逐步显示；每个讲解时刻只保留必要的短词或短句，字体清楚，不能依赖生成图片中的乱码或小字。
- 人物若出现，双臂完整，姿势和道具必须直接说明动作。
- 不使用固定品牌 IP，不做复杂拼贴。

判断标准：关掉旁白后，观众仍能在一秒内说出图里“谁把什么交给谁”或“哪个结果走哪条路”。

每张插画登记唯一编号、对应概念、源文件和唯一连续使用区间。同一连续段落内可逐层出现、动作演示和局部聚焦；退场后不能在另一段落重新使用，也不能通过裁切、镜像、换色或改标签规避。统一角色或画风可以保留，但新插画必须为新概念重设计主体动作、构图与关系。总结镜头另做总结图，不重新拼贴已用插画。

流程画面要能直接回答“输入是什么、谁执行哪个操作、输出是什么”；分岔图写清触发条件和去向，因果图写清原因与结果。抽象比喻旁补简短中文对应关系；若还需要额外长篇解释才能明白，重画关系、拆镜或替换比喻。放大检查源素材，按实际显示尺寸检查手机可读性，不用模糊放大图承载重点。

### 手绘文字预留与口播联动

设计手绘插画前读取 [文字预留与口播联动规范](illustration-text-sync.md)，从当前段落提取 2–3 个辅助信息点，建立文字联动表。先规划干净文字区并用实际文字试排，再确认无文字底图；文字使用独立可编辑层，不在底图中生成标签、占位字或区域编号。

- 在构图阶段预留 2–3 个干净区域，避开主体、字幕和平台安全区；人物、道具、纹理和运动路径不得侵入。
- 文字联动表记录位置、对应原句、入场起点、完整可读时刻、结束及保留/弱化/退出策略，与关键词同步表共用真实音频时间锚点。
- 按口播逐项出现，同一时刻只强调当前项；步骤、因果或对比可累计保留，信息无关或过密时淡出前项或切镜。不能提前展示全部文字或平均分配时间。
- 插画缩放、裁切或换版后重新检查区域落点。单幅图仍只解释一个中心意思，保留插画唯一使用规则。

## 8. 精剪感来自哪里

精剪感不是转场数量，而是以下动作形成连续因果：

- 旧画面向某个方向让位，新画面从同一方向或相反方向接入。
- 新镜头先建立标题和主素材，再让节点跟随口播出现。
- 字幕按真实口播的独立时间线换句；镜头交接不能重置字幕，也不能把换句推迟到转场结束。口播在转场中换句时，字幕照常切换且始终置顶。
- 章节变化比普通切镜多一个角标或轻微尺度变化，但不打断语速。
- 数字、勾选、连线和卡片只在对应关键词被说到时运动。
- 重要画面允许停住，让观众读完；静止不是卡顿，空白和无信息遮罩才是。

## 9. 声音

旁白始终是第一声部。为合适的事件实际编排音效：转场用短轻扫声或翻页声，操作用点击或落点声，成功与状态变化用轻确认声，风险用克制的提示声。根据语义选择，不机械覆盖每个镜头或每个词；流程篇不能只有口播和背景音乐而完全缺少适合的事件音效，用户明确要求无音效时除外。

音效入点或重音对齐画面事件，统一写入关键词同步表；用音轨时间偏移安排并预加载，不用浏览器定时器触发。音效须有可追溯来源与使用许可。单独检查音效轨，再正常速度试听最终混音：音效可辨但不抢旁白，必要时降增益、避开重叠或缩短尾音。检查响度、True Peak、削波和拼接边界；片尾声音与画面统一截止，句尾保留自然衰减。

## 10. 按改动范围验收

开始制作前登记改动范围和受影响时间段，并按 [精选验收表](qa-checklist.md) 执行：

- 新制作或全局改动：所有场景、所有转场和全片音画同步都在范围内；生成全场景接触表，整片正常速度观看和试听。
- 局部修改：检查受影响段、前后相邻边界及其字幕和声音，正常速度观看和试听这些片段；记录实际时间范围，并明确“未做整片正常速度观看和试听”。不因局部通过而声称整片通过。
- 精确截断：检查末句、截止点前后、片尾自然衰减及音画字幕统一结束；若同时改变全局时长映射或其他段落，扩大到实际影响范围。
- 全局字幕样式、共享布局、全局音轨、时间映射、帧率或渲染设置变化会影响整片，不能按局部修改降级。最终 MP4 仍须完整解码、核对规格；相称范围主要用于逐镜头抽帧和人工观看。

不得把未执行的检查写成通过。保留旧版、源工程和范围记录，必要时依据新发现扩大验证范围。
